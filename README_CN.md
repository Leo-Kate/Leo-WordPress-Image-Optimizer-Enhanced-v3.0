## 💡 使用技巧

### 最佳实践

1. **首次使用**
   - 先在测试环境测试
   - 备份网站和数据库
   - 小批量测试（5-10张）
   - 检查转换质量
   - 然后全量转换

2. **质量设置**
   ```
   照片/摄影作品: 85-90
   产品图片: 80-85
   文章配图: 75-80
   图标/UI元素: 90-95
   ```

3. **性能优化**
   - 启用对象缓存（Redis/Memcached）
   - 使用ImageMagick（如可用）
   - 启用CDN加速图片分发
   - 批量大小根据服务器性能调整

4. **空间管理**
   - 首次转换保留原图
   - 确认效果满意后清理原图
   - 定期检查错误日志
   - 使用格式筛选批量清理

## 🛠️ 故障排查

### 常见问题

**Q: 脚本404错误**
```bash
# 解决方案：
1. 检查文件权限 (644)
2. 清空WordPress缓存
3. 刷新固定链接
```

**Q: 管理面板不响应**
```bash
# 解决方案：
1. 清空浏览器缓存
2. 检查浏览器控制台错误
3. 禁用其他插件测试冲突
```

**Q: 批量转换很慢**
```bash
# 解决方案：
1. 降低批量大小到3-5
2. 检查PHP内存限制（推荐256MB+）
3. 使用ImageMagick替代GD
4. 启用对象缓存
```

**Q: 内存不足错误**
```bash
# 解决方案：
1. 增加PHP memory_limit到256MB或更高
2. 减小批量大小
3. 限制最大图片尺寸
```
