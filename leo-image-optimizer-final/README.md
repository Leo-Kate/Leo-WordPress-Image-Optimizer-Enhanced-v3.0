# WordPress Image Optimizer Enhanced

本插件在原有的 WebP/AVIF 批量优化功能基础上进行了大量改进，可自动或手动将媒体库中的图片转换为现代格式并提供完善的队列控制、状态反馈、日志记录及安全的原图管理。以下为插件使用说明和注意事项。

## 功能概述

* **自动转换上传图片** – 新上传的 JPEG/PNG 会根据设置自动转换为 WebP/AVIF，可在后台设置中自由启用或关闭。
* **批量转换工具** – 一键扫描媒体库中未转换的图片，分批异步处理，支持暂停/恢复，实时显示处理数量、剩余数量、错误数量以及进度条。
  当点击“停止转换”时插件会立即清除处理计数并重置进度条，刷新页面不会再出现“停止转换”按钮或残留进度，下一次执行将从零开始。
* **原图保留与清理** – 默认保留原始文件以便审核或恢复，可勾选自动删除原图；提供手动清理工具，可按格式、文件大小筛选删除。
* **元数据修正** – 转换后自动更新附件 MIME 类型，后台媒体库显示为真实的 image/webp 或 image/avif，避免“类型错误”的问题。
* **服务端配置提示** – 自动尝试向站点 `.htaccess` 写入 WebP/AVIF MIME 指令；若检测为 Nginx 则提供提示代码供管理员手动配置。
* **MIME 测试工具** – 输入图片 URL，可检测服务器返回的 Content‑Type、文件大小与缓存头，判断是否正确返回 WebP/AVIF。
* **懒加载与 CDN 支持** – 可启用图片懒加载并自定义触发距离；支持配置 CDN 前缀加速附件访问。

## UI 优化

为了提升管理体验，插件设置页使用可折叠面板和响应式布局对各功能模块进行了重新排版。页面整体取消了默认的最大宽度限制，卡片会自动充满可用空间，减少右侧留白；仅常用的“插件设置”区域默认展开，其他部分（如安全性与原图清理、MIME 测试工具、批量转换现有图片）在需要时点击标题即可展开/收起，大幅减少滚动距离。

## 安装与更新

1. 登录 WordPress 后台，依次进入「插件 → 安装插件 → 上传插件」。
2. 选择解压得到的 `leo-image-optimizer.zip` 或者该目录重新打包后的 zip 文件，点击“立即安装”。
3. 安装完成后点击“启用插件”。插件启用后即处于运行状态，无需额外激活。
4. 更新插件时重复以上步骤上传新压缩包，覆盖旧版本即可。建议更新前备份站点。

## 设置说明

在 WordPress 后台左侧「媒体 → Image Optimizer」即可进入插件设置页。主要选项说明如下：

| 设置项 | 说明 |
|--------|------|
| **WebP 质量** | 控制自动转换生成 WebP/AVIF 的品质（1–100），数值越高图像越清晰，文件越大，推荐 70–90。 |
| **批处理大小** | 批量转换时每批处理的图片数量，默认 5。较小的值可以减少服务器负载，避免超时。 |
| **图片处理器** | 选择用于生成 WebP/AVIF 的图像库。如果服务器支持 Imagick，通常性能更好；否则使用 GD。插件会检测可用性并禁用不可用选项。 |
| **自动转换新上传图片** | 勾选后所有新上传的图片都会自动转换为 WebP/AVIF；取消勾选则不自动转换。 |
| **启用图片懒加载** | 勾选后页面中的图片将在即将进入可视区域时才加载，提高首屏速度。 |
| **懒加载触发距离** | 当图片距离可视区域多远时开始加载，可填写像素或百分比，如 `200px` 或 `50%`。 |
| **启用 CDN** | 勾选后启用图片 CDN 加速功能，需要填写下方的 CDN 域名。 |
| **CDN URL** | CDN 的完整前缀，例如 `https://cdn.example.com`，不要以 `/` 结尾。启用后插件会将附件 URL 替换为该地址。 |
| **自动删除原图** | 转换成功后立即删除原始文件以节省存储空间。默认关闭，建议在确认无误后开启。 |
| **手动清理原图** | 提供按格式和文件大小批量删除原始文件的功能。例如设置格式 `jpg,png` 且大小 `2` MB，则只删除大于 2 MB 的 JPEG/PNG 原图。删除操作不可恢复，请谨慎使用。 |

保存设置后即时生效，无需刷新。需要注意以下几点：

* 若启用 **自动转换新上传图片**，插件将在 `wp_handle_upload` 钩子中异步处理文件，并根据设置决定是否删除原图。
* 批处理转换为异步执行（通过 WP‑Cron 调度），同时在浏览器端轮询进度，避免页面卡顿。如发现进度停留不动，可保持页面开启一段时间或手动点击“开始批量转换”再次触发。
* 批量转换支持随时点击“停止转换”按钮中断队列。停止后可以重新点击开始以继续未完成的任务。进度条和统计信息会实时更新。
* 插件在每次转换之前会在附件元数据 `_manus_webp_converted` 中记录状态，因此重复执行批转换不会重新处理已完成的图片。

## 原图保留与清理

为了保障安全，插件默认保留原始文件。管理员可以通过如下方式管理原图：

1. **自动删除原图** – 在设置页勾选后，转换成功即删除原图。删除前插件会将原图路径保存到 `_manus_original_file` 附件元字段，以便未来恢复或手动清理。
2. **手动清理原图** – 设置格式和大小后点击“清理原图”按钮，插件会遍历所有已成功转换的附件，删除符合条件的原始文件。删除完成后会提示删除和保留的数量。

> 提示：若要恢复原图，可通过 FTP 或服务器备份提取 `_manus_original_file` 字段记录的路径，然后手动上传并更新附件。

## MIME 测试工具

在设置页底部提供“WebP/AVIF MIME 测试工具”。输入一张图片的 URL（可以是本站上传的 WebP/AVIF，也可以是其他站点的），点击“检测 MIME”，插件将发送 HEAD 请求并显示以下信息：

* **MIME 类型** – 服务器返回的 `Content-Type` 头，若为 `image/webp` 或 `image/avif` 表明配置正确。
* **文件大小** – 返回的 `Content-Length`，以 MB 显示。
* **缓存信息** – 常见缓存头（如 `x-cache`、`cache-control` 等）。
* **检测结果** – 判断是否为 WebP/AVIF 格式。

此工具有助于诊断服务器未配置 MIME 映射或 CDN/缓存层未正确返回内容类型的问题。

## 服务器配置提示

为了确保浏览器能够正确识别 WebP/AVIF 文件，需要配置服务器返回正确的 MIME 类型：

### Apache

插件会在启用时尝试向站点根目录或上传目录的 `.htaccess` 文件添加以下指令：

```apache
AddType image/webp .webp
AddType image/avif .avif
```

如自动添加失败或仍出现 MIME 错误，请手动将上述内容添加到站点的 `.htaccess` 中，然后保存即可。

### Nginx

Nginx 配置需管理员手动修改。请在主配置 `http {}` 或对应站点 `server {}` 块中添加：

```nginx
types {
    image/webp webp;
    image/avif avif;
}
```

保存配置并重载 Nginx 后生效。

## 注意事项

* **备份优先** – 批量转换和删除原图前请务必备份网站和数据库，避免数据丢失。
* **服务器性能** – 批量处理过程中请留意服务器资源使用；可适当调小批处理大小。若后台过慢，可等待队列运行完成后再操作。
* **版权与法律** – 使用压缩与转换图片时请确保拥有图片版权或使用授权。

完成以上设置后，您的 WordPress 站点即可安全地批量转换图片为 WebP/AVIF 并提升网站性能。如有问题请查看错误日志或联络插件作者。祝使用愉快！
